# JA Security Publication System

## Concept: Authority Observatory

The suite presents security policy as a visible chain from identity through decision, proof, enforcement, and audit—not as a pile of access-control fragments. The visual system uses an obsidian field, teal identity and integrity paths, blue decision transitions, violet proof/provenance signals, and restrained gold certification accents.

## Hierarchy

1. Source and language identity
2. Principal, role, resource, and scope graph
3. Decision rules, precedence, and proof obligations
4. R12 policy identity
5. Modeled or native enforcement outcome
6. MCRT receipt and certification decision

## Air-gap rules

Use only local Markdown, CSV, JSON, JSONL, Python, and SVG. Require no remote fonts, images, HTML, CSS, JavaScript, telemetry, or network assets. Preserve monochrome readability, compact Windows paths, and secret-free examples and receipts.
