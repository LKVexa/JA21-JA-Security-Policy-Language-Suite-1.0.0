# Governance Charter

## Purpose

Govern this suite as a language, evidence, education, and conformance product for JA21 security policy engineering.

## Decision lenses

SOPHIA reviews semantic coherence; CHARLOTTE reviews information architecture and explanation; LANDON reviews implementation feasibility; Professor reviews proof and pedagogy; Podium reviews publication and certification readiness.

## Non-negotiable controls

- Default deny and fail closed.
- No hidden network or process authority.
- No secret values in source or evidence artifacts.
- Delegation cannot widen authority.
- Revocation and expiry must invalidate stale decisions.
- Optimization cannot remove precedence, proof, explanation, lifecycle, audit, or provenance gates.
- No native-execution or certification claim without reproducible evidence.
