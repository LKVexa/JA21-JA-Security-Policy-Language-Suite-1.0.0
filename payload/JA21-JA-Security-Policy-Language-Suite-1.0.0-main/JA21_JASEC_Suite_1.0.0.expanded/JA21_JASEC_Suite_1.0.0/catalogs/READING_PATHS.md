# Role-Based Reading Paths

## Policy author
Read Chapters 1–16, then use positive, boundary, and integration programs to compose identity, resource, decision, delegation, and lifecycle policies.

## Compiler engineer
Read Chapters 2–8 and 17–21. Use negative and security records to define syntax, resolution, type, effect, capability, precedence, and proof diagnostics.

## Runtime and sandbox engineer
Read Chapters 9–16 and 18–22. Focus on fail-closed evaluation, revocation, expiry, redaction, process/network isolation, audit, replay, and MCRT receipts.

## Security reviewer
Read Chapters 4–16 and 20–21. Audit authority expansion, conflict resolution, secret exposure, missing approvals, stale proofs, and enforcement gaps.

## Instructor and certifier
Use the curriculum, workbook, certification guide, and all ten validation classes. Require explicit separation of modeled, structural, native, and certified evidence.
